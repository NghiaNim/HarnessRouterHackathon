Hive keeps everyone's coding agents on the same page.

Each teammate runs their own AI coding agent (Claude Code, Codex, …). Hive gives all of them one shared memory: the rules your team agreed on and what each agent already figured out. Nobody re-explains things in Slack, and no agent re-reads the whole codebase to rediscover them.

How it works

  1. 1

    You correct your agent

    “No, use httpx, not requests.” When the session ends, Hive turns what you said into a proposed team rule, quoting you as evidence.

    {{ waiting | length }} waiting for a human →
  2. 2

    A human approves it

    Agents can only propose. A person clicks Accept on Team rules, and the rule becomes binding for every agent.

    {{ active_rules | length }} active rule{{ "" if active_rules | length == 1 else "s" }} →
  3. 3

    Every agent starts informed

    When anyone starts a session, Hive gives their agent a short briefing: the rules for the files it will touch, plus what teammates' agents learned. See one below.

    {{ note_count }} session note{{ "" if note_count == 1 else "s" }}{% if people %} from {{ people | length }} teammate{{ "" if people | length == 1 else "s" }}{% endif %}
  4. 4

    Mistakes get caught soon

    Hive flags edits that break a rule, and warns when two agents are changing the same file at the same time.

Where does Hive run? In your terminal, Claude Code hooks call Hive automatically when a session starts and ends, so there's nothing to copy-paste. This dashboard is where humans approve rules and see what the agents know.
